# mlip

Minimal, MLIP‑first workflows for molecular simulation.

Docs are in `docs/` and rendered with MkDocs.

Read the docs: https://emainas.github.io/mlip/

Quickstart:

```bash
conda env create -f environment.yml
conda activate mlip
pip install -e .
mlip --help
```

Local docs:

```bash
pip install mkdocs
mkdocs serve
```
